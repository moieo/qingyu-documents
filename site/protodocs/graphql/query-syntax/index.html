    使用变量

    1
2
3
4
5
6
7
8
    query GetUser($userId: ID!, $limit: Int = 10) {
  user(id: $userId) {
    name
    posts(first: $limit) {
      title
    }
  }
}

    指令（Directives）

    @include 指令

    1
2
3
4
5
6
7
8
9
    query GetUser($id: ID!, $withPosts: Boolean!) {
  user(id: $id) {
    name
    email
    posts @include(if: $withPosts) {
      title
    }
  }
}

    @skip 指令

    1
2
3
4
5
6
    query GetUser($id: ID!, $skipEmail: Boolean!) {
  user(id: $id) {
    name
    email @skip(if: $skipEmail)
  }
}

    @deprecated 指令

    1
2
3
4
    type User {
  name: String!
  fullName: String! @deprecated(reason: "使用 name 字段代替")
}

    性能优化技巧

    1. 只请求需要的字段
    2. 使用分页避免大数据集
    3. 合理使用片段减少重复代码
    4. 利用数据加载器减少 N+1 查询
    5. 使用持久化查询减少网络开销
