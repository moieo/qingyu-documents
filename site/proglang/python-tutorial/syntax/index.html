    语法基础

    Python 的语法设计简洁明了，易于理解和学习。本章将介绍 Python 的基本语法规则和代码风格。

    基本语法规则

    1. 缩进

    Python 使用缩进来表示代码块，而不是大括号 {}。这是 Python 最显著的特征之一。

    1
2
3
4
5
6
7
8
9
    # 正确的缩进
if True:
    print("这是正确的缩进")
    if True:
        print("这是嵌套的缩进")

# 错误的缩进会导致 IndentationError
if True:
print("这会报错")  # IndentationError

    缩进规则： - 通常使用 4 个空格作为一个缩进级别 - 同一代码块的语句必须保持相同的缩进级别 - 不要混用空格和制表符

    变量命名规则

    遵循 PEP 8 命名规范：

    1. 变量名：小写字母，单词间用下划线分隔（snake_case）。
    1
    user_name = "Alice"
    1. 常量名：全大写字母，单词间用下划线分隔（UPPER_CASE）。
    1
    MAX_USERS = 100
    1. 类名：首字母大写的驼峰命名法（CamelCase）。
    1
2
    class UserProfile:
    pass
    • 解释：统一的命名规范提高代码可读性。
    • 适用场景：适用于所有 Python 代码。

    代码风格指南 (PEP 8)

    1. 行长度：每行不超过 79 字符。
    2. 导入顺序：标准库 → 第三方库 → 本地模块。
    3. 空格使用：
    4. 运算符两侧加空格：a = b + c
    5. 逗号后加空格：[1, 2, 3]

    小结

    本章介绍了 Python 的基本语法规则，包括：

    • 缩进：Python 使用缩进表示代码块
    • 注释：使用 # 进行单行注释，使用三引号进行多行注释
    • 标识符：变量、函数、类的命名规则
    • 数据类型：数字、字符串、布尔值等基本类型
    • 运算符：算术、比较、逻辑、赋值运算符
    • 输入输出：print() 和 input() 函数
    • 代码风格：遵循 PEP 8 规范

    掌握这些基础语法是学习 Python 的第一步，为后续学习更复杂的概念打下坚实的基础。
